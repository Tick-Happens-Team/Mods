# TickHappens Mods

This directory is the planned community catalog for the in-game Workshop. Mods will be submitted by pull request and published as versioned ZIPs through GitHub Releases. GitHub Pages will serve the signed catalog index.

A mod contains a `mod.toml` manifest, JSON content, PNG artwork, and OGG audio. See the [mod format](https://github.com/Tick-Happens-Team/Game/blob/dev/docs/MODDING.md) and the [contribution guide](CONTRIBUTING.md).

GitHub Actions runs the submission validator for pull requests and pushes. Signed catalog publication and Workshop installation are tracked in the [roadmap](https://github.com/Tick-Happens-Team/Game/blob/dev/ROADMAP.md).

Each mod declares its own license and asset provenance. See [Catalog and mod licensing](LICENSE.md).
